# makeathon-2026-LEGENDS-FinDoc-AI

FinDoc Auditor AI is a React + Express app for searching a curated receipt set, opening the exact matching document, and asking a strict Gemini-powered auditor questions about the selected receipt.

## Run Locally

Prerequisites: Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Create `.env.local` from `.env.example` and set `GEMINI_API_KEY`.
3. Run the app:
   ```bash
   npm run dev
   ```

## Build

```bash
npm run build
npm run start
```
